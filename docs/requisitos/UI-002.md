# UI-002 — Temas e cores pessoais

Status: implementado localmente em 22/09/2026; aguardando revisão e Pull Request.

## Objetivo e limites

Permitir que cada pessoa escolha a aparência da interface do protótipo UI-001.
O padrão é tema claro com a paleta roxa. As preferências iniciais permanecem no
navegador; o salvamento no perfil autenticado será tratado na etapa funcional de
identidade e exigirá migration própria. Esta entrega não altera permissões,
dados de negócio, API, banco, e-mail nem relatórios publicados.

As paletas foram definidas a partir da referência visual fornecida pelo
mantenedor e do verde já empregado no protótipo. Elas não importam marcas,
ícones ou outros ativos de terceiros.

## Atores e pré-condições

Qualquer visitante da demonstração pode abrir o painel **Aparência** na barra
superior. Não há login no UI-001. O navegador deve aceitar armazenamento local;
se ele estiver indisponível, a aparência ainda é aplicada na sessão atual, sem
declarar que foi salva.

## Opções

| Configuração | Opções | Padrão |
| --- | --- | --- |
| Tema | Claro, escuro, usar aparência do sistema | Claro |
| Cor de destaque | Roxo, laranja, azul, verde | Roxo |

As cores principais são: roxo `#65439A`, laranja `#E87500`, azul `#6592CF` e
verde `#37745A`. Cada paleta possui valores próprios para superfícies, texto,
bordas, foco e estados interativos, sem usar a cor como único meio de comunicar
um estado.

## Fluxo

1. A pessoa abre **Aparência** na barra superior.
2. Seleciona um tema e uma cor. A mudança é aplicada imediatamente a toda a
   interface.
3. A seleção é armazenada localmente e restaurada em uma nova abertura ou
   recarga da página.
4. Ao escolher **Usar aparência do sistema**, a interface acompanha a
   preferência clara/escura do sistema enquanto a página estiver aberta.

## Critérios de aceitação

| ID | Resultado verificável |
| --- | --- |
| UI2-01 | Primeiro acesso exibe tema claro e paleta roxa. |
| UI2-02 | A pessoa pode selecionar claro, escuro ou aparência do sistema; a mudança afeta toda a interface imediatamente. |
| UI2-03 | A pessoa pode selecionar roxo, laranja, azul ou verde; a escolha é perceptível em controles e foco sem comprometer a leitura. |
| UI2-04 | Tema e cor permanecem após recarregar a página no mesmo navegador. |
| UI2-05 | O seletor é operável por teclado e comunica opção selecionada; todos os temas preservam foco visível e contraste AA para texto e controles essenciais. |
| UI2-06 | A impressão continua com fundo claro e texto escuro, independentemente da aparência de tela. |
| UI2-07 | Não há requisição para API, alteração de banco, migration ou dado real nesta etapa. |

## Dados, recuperação e evolução

As preferências são serializadas sob uma chave de armazenamento local específica
da UI-002 e contêm somente `themeMode` e `accent`. Remover os dados do navegador
restaura o padrão. Depois da IDN-001C, uma migration e uma API poderão guardar a
mesma preferência por usuário autenticado; a preferência remota deve prevalecer
sobre o padrão, sem substituir uma escolha local antes da autenticação.

## Testes

Ver [cenários UI-002](../testes/cenarios-ui-002.md). Os testes verificam a
