# PBL-001 — Publicação da prévia UI-001

Status: **implementação autorizada pelo mantenedor em 21/09/2026**.
Relacionada a [UI-001](UI-001.md) e à
[proposta de hospedagem](../operacao/hospedagem-proposta.md).

## Objetivo e limites

Disponibilizar uma URL pública para avaliar o protótipo navegável UI-001 em
computador e celular. A prévia usa apenas os dados fictícios mantidos no
navegador. Não executa API, migrations, autenticação, envio de e-mail ou
persistência de dados.

## Configuração proposta

O arquivo `render.yaml` descreve um Static Site gratuito no Render. Ele instala
dependências com lockfile, executa o build do pacote web e publica somente
`apps/web/dist`. A origem do repositório é a branch `main`; a URL gerada pelo
Render é o único artefato de publicação desta etapa.

## Critérios de aceitação

| ID | Resultado esperado |
| --- | --- |
| PBL-01 | O build reproduzível da UI-001 conclui com `pnpm build` |
| PBL-02 | `render.yaml` descreve Static Site, branch `main`, build com lockfile e publicação de `apps/web/dist` |
| PBL-03 | A URL pública abre o protótipo e não requer segredo, conta, banco, Auth0 ou domínio próprio |
| PBL-04 | A prévia informa que usa dados fictícios e não representa uma implantação do piloto operacional |

## Operação e recuperação

O Render pode atualizar a prévia a cada envio para `main` após a conexão ser
criada no painel. Pausar ou excluir o Static Site interrompe a prévia, sem
afetar dados porque ela não possui banco. A publicação do piloto funcional será
uma entrega diferente, com autorização específica, migrations serializadas e
serviços de identidade e dados separados.
